# ISO 9660 只读文件系统

ISO 9660 是 OpenXJ380 的内建公共文件系统驱动，闭源 XJ380 使用同一份
Apache-2.0 实现。驱动在 FAT、ext4、NTFS 之后注册，通过已有 VFS 接口读取。

## 支持范围

- ISO 9660 Level 1、2 普通文件及目录，以及 Level 3 多区段文件。
- 单卷、2048 字节逻辑块。底层设备扇区与 ISO 逻辑块分别处理，复用块设备的
  字节读取接口；不要求底层设备也是 2048 字节扇区。
- Joliet UCS-2 大端名称转 UTF-8。存在有效 Joliet 描述符时选择其目录树，
  否则使用基本 ISO 目录树。非法 UCS-2、超长名称及含路径分隔符的名称被拒绝。
- 基本 ISO 名称以 ASCII 小写显示并按 ASCII 忽略大小写查找；Joliet 保留大小写并精确匹配。
- 普通文件名称隐藏数字版本后缀和末尾点。同名文件的不同版本显示最高版本；
  相同版本的重复目录项作为错误拒绝。关联文件不进入普通文件名称空间。
- 随机读取、EOF、64 位大小、多区段跨界读取，以及真实卷容量的 statfs。

所有挂载均只读，普通文件权限为 0444，目录为 0555。创建、写入、删除、
重命名、截断及元数据修改受到 VFS 的 EROFS 保护；底层解析器没有写回调。

本版不解析 Rock Ridge/SUSP 扩展，因而不会恢复这些扩展中的符号链接、
POSIX 属性和重定位目录。其目录树仍按基本 ISO 或 Joliet 名称空间展示。
Rock Ridge 是后续独立增强阶段，不能将本版作为 POSIX 光盘树的完整还原器。
UDF、音频 CD、原始 2352 字节扇区镜像、跨卷文件、交错文件、多会话选择、
写入/刻录及普通文件的 loop 挂载也不在本版范围内。

## 挂载与生命周期

普通系统启动在根目录挂载后探测整盘 ISO，成功后挂载到 `/mnt/<设备名>`。
热插拔设备在分区扫描租约释放后进行同样探测。驱动只接受实际 devfs 块设备，
手动挂载可以使用原始 `/dev/<设备名>`，或 `iso9660:/dev/<设备名>` 来源字符串，
后者显式选择 ISO 探测。现有 VFS 挂载调用和用户 ABI 均保持原样。

挂载保留设备节点、注册代次和物理区间租约，拒绝重叠挂载。混合 ISO 的
整盘与内部 GPT/FAT 分区也遵循此限制。安装器模式不自动挂载 ISO，以保留
其源介质和安装目标的独占规则。此驱动不更改 UEFI/El Torito 启动流程。

文件仍有外部引用时卸载返回忙碌。目录先在私有树中完整解析，再短暂持有 VFS
锁发布；解析、分配、释放和设备读取均在自旋锁之外。读失败或操作所有者异常
终止时保留不能安全回收的上下文，拒绝继续使用，直到重启。

## 实现上限与验证

最多同时保留 16 个挂载上下文；描述符序列最多扫描 256 项；每个目录最多
64 MiB、65536 个逻辑目录项；
每个文件最多 1024 个区段；UTF-8 名称最多 255 字节。超过上限明确返回错误。
文件区段按需从盘面读取，无须在每个 VFS 节点中分配最大区段数组。

公共主机测试：

```sh
python3 -m unittest discover -s OpenXJ380/tests -p test_iso9660.py -v
python3 OpenXJ380/tools/check_iso9660_sources.py
```

在独立 OpenXJ380 仓库中，去掉上述 `OpenXJ380/` 前缀。测试使用 ASan/UBSan，
覆盖真实 xorriso 生成的 Level 1–3/Joliet 镜像、大目录、损坏记录、非连续区段
和超过 4 GiB 的稀疏文件。QEMU 集成测试使用独立测试内核与启动盘副本；
生产镜像、测试 ISO 均不由探针修改。父工程的运行命令为：

```sh
python3 tests/run_iso9660_qemu.py --boot-image /path/to/XJ380.img
```

运行器默认分别验证 AHCI 光驱、q35 上的 PIIX IDE 光驱，并检查正常登录进程
启动。探针覆盖只读操作拒绝、重复区间挂载、损坏镜像回收、重挂载，以及四个
线程在两个挂载点并发读取时的内容和卸载生命周期。主机侧另外核对源 ISO 哈希。

2026-11-21 验证：两个工程的 `ninja all` 构建通过；父工程新建临时 ext4 镜像
通过 e2fsck；IDE/AHCI 各 57 项运行时检查及登录进程启动通过。主机解析与来源
清单测试、VFS/块设备/任务退出回归、挂载信息、镜像暂存及构建图测试均通过。

来源与许可证边界见 `driver/fs/iso9660/PROVENANCE.md`；对应材料随系统安装到
`/system/licenses/native-iso9660`。
