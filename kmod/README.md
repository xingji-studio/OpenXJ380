# Kernel Modules

`system/kmod/` contains loadable kernel modules that are built into `.sys` artifacts
and copied into `/system` in the disk image.

Current layout:

- `system/kmod/e1000/`: loadable Intel E1000 network driver
- `system/kmod/xhci/`: loadable xHCI host controller driver foundation
- `system/kmod/netserver/`: networking module sources and third-party stack code

Boundary rule:

- Put code here only if it is intended to be linked as a shared kernel module.
- Keep code in `kernel/` only if it must be part of the core kernel image.
- Keep code in `driver/` only if it is a built-in driver linked into `kernel.krl`.

Build:

- First-party module builds are generated by `tools/gen_ninja.py` and run with
  `ninja -f build.ninja kmods`.
